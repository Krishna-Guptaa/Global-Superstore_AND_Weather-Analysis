## 📌 Project Overview

This repository contains two end-to-end Power BI analytics projects demonstrating data visualization, dashboard development, and business intelligence techniques.

### Project 1: Global Superstore Analysis
Analyzes sales, profit, customer behavior, regional performance, and product trends using the Global Superstore dataset.

### Project 2: Weather Analysis
Explores weather patterns, temperature trends, humidity, rainfall, and other climate-related metrics through interactive Power BI dashboards.

These projects showcase data cleaning, data modeling, DAX calculations, and interactive dashboard design using Microsoft Power BI. :contentReference[oaicite:0]{index=0}

## 🎯 Objectives

- Build interactive business dashboards.
- Analyze sales and business performance.
- Explore weather trends using historical data.
- Practice data modeling and DAX.
- Generate meaningful insights for decision-making.
